# 화면 확인 자료

2026-10-26 운영 주소의 격리 브라우저에서 저장한 전체 학습 문서 화면이다.
배포 판은 `6778cc0e-9734-43cf-be56-eaac577738a6`다. 강PD의 학습 수행을 기록하지 않았다.

- `full-document-desktop-start.png`: have 설명·공개 예시·일곱 문제를 처음부터 가진 문서의 시작, 1440×960 CSS px.
- `full-document-desktop-reading.png`: 문서 중간의 3번과 이어지는 4번 문제. 목차·자료·대화는 옆에 머물며 읽는 문제와 입력 대상은 구분한다.
- `full-document-desktop-seventh.png`: 앞 문제를 제출하지 않고 7번을 골라 쓴 초안과 문서 끝. 전체 문제는 계속 표시한다.
- `full-document-desktop-compact.png`: 1100×720 CSS px에서 5번을 읽으며 7번 초안을 유지하는 상태. 긴 입력은 대화 안에서 스크롤한다.
- `full-document-mobile-reading.png`: 390×844 CSS px Chromium 에뮬레이션의 연속 읽기. 한 문제 뒤에 다음 문제가 바로 이어진다.
- `full-document-mobile-answer.png`: 문서에서 명시적으로 이동한 7번 쓰기 입력. 초안을 자동 제출하지 않는다.
- `full-document-mobile-short.png`: 320×430 CSS px에서 7번의 제목·풀이 버튼·장면·문서 끝을 읽는 상태.

검증 초안은 강PD의 학습 기록이 아니며 이 화면 저장 과정에서는 AI를 호출하지 않았다.
화면 일곱 장에서 가로 넘침·중복 DOM ID·브라우저 오류는 발견하지 못했다. 실제 iOS 키보드·화면 읽기 도구의 검증은 아니다.
전체 문서 공개·자유 선택·위치 보존과 모델 판단의 근거는 `docs/tasks/content-chat-workspace.md`에 있다.
`unified-input-*`는 이전 입력 통일, `content-chat-*`는 이전 두 칸 배치이며 그 밖의 그림도 이전 시안의 화면이다.
현재 연속 문서 디자인의 근거로 쓰지 않는다.
