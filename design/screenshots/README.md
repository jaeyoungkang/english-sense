# 화면 확인 자료

2026-10-26 운영 주소의 빈 브라우저에서 저장한 현재 화면이다. 실제 학습 수행을 만들지 않았다.

- `workspace-desktop.png`: 상단 have 감각 자료와 하나의 대화, 1440×960 CSS px.
- `workspace-mobile-reference.png`: 같은 흐름의 휴대폰 화면, 390px 폭 Chromium 에뮬레이션.
- `workspace-mobile-short.png`: 320×430 CSS px의 자료·대화·입력 영역.

`workspace-mobile-scene.png`와 `workspace-mobile-chat.png`는 이전 패널 방식의 확인 자료다.
그 밖의 그림은 이전 소개 중심 시안의 확인 자료이며 현재 운영 화면의 증거로 쓰지 않는다.
