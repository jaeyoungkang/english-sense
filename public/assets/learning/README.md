# 학습 시각 자료

`titanic-corridor.webp`는 2026-10-26 이미지 생성 도구로 만든 학습용 장면 재구성이다.
기존 have 연습 첫 문항의 복도·문·졸린 아이를 시각화했으며 원서의 실제 삽화나 역사 사진이 아니다.
복도의 세부·조명·의상·선박 구조는 설명을 위한 창작이고 원문의 사실을 증명하지 않는다.
정답 문장·선택지 분류·문법 설명을 이미지에 넣지 않았다. 장면의 실제 판단 자료는 화면의 본문과 질문이다.

생성 원본은 로컬 생성 도구의 보관 위치에 두었으며 앱에는 WebP 형식으로 최적화한 사본을 사용한다.
생성된 이미지를 실제 학습 수행이나 강PD가 선택한 디자인으로 기록하지 않는다.
