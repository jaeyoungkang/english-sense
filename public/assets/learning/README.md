# 표현의 감각 이미지

`have-sense.webp`는 2026-10-26 이미지 생성 도구로 만든 have 감각의 시각화다.
정본은 study-and-learn의 감각 사전 have 줄과 `content/scene-sense/have.md`다.
사람을 기준으로 한 연두색 영역 안에 손전등·하트·시계·몸 모양·체크리스트와 발자국이 함께 놓여 있다.
획득 동작·들어오는 화살표·소유권 표식·정답 문장을 넣지 않았다.

그림과 함께 '내 영역 안에 놓여 있다. 물건뿐 아니라 몸, 마음, 시간, 할 일, 지난 일도 내 영역이 됩니다'라는
본문을 둔다. 도상과 배치는 정본 감각을 옮긴 설계 선택이며 그림만으로 감기·특정 의무를 확정하지 않는다.
별도 에이전트가 원문 감각과 실물을 대조했으며 근접 본문을 함께 제공하는 조건으로 사용 가능하다고 검토했다.
학습 효과나 강PD의 선호를 검증한 것은 아니다. 생성 원본은 도구의 보관 위치에 두고 앱에는 WebP 사본을 쓴다.

`titanic-corridor.webp`는 이전 해석에서 만든 책 장면 재구성 사본이다. 현재 기본 학습 화면에서는 쓰지 않는다.
원서 삽화·역사 사진이 아니며 삭제나 재사용을 의미하는 자료가 아니다.
