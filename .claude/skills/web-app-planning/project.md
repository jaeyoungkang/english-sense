# web-app-planning — 이 프로젝트에 맞춘 것

## 읽을 곳과 계약을 둘 곳

- 승인된 개인 학습 범위는 `docs/learning-service.md` "승인된 약속"에 있다. 현재 구현과 미정인 선택은 같은 문서의
  "현재 구현과 남은 일"에서 읽는다. 학습 내용과 기존 수행 기록의 정본은 study-and-learn 프로젝트다.
- 웹앱 제작 판단은 `knowledge/domain/web-app-production.md`, 구조 판단은
  `knowledge/domain/web-app-architecture.md`, 작업의 기대·결과와 인계는 `knowledge/production.md`를 읽는다.
- 작업이 이미 가리키는 계약 문서가 있으면 고친다. 이슈만 있거나 계약이 없으면 `docs/tasks/<과업>.md`에 계약 하나를
  둔다. 이슈는 계약을 연결하고, 수용 기준은 계약 문서가 소유한다. 기대와 결과를 이슈에 남기는 방법은
  `knowledge/production.md` "규칙"의 "일을 시작할 때"를 따른다.
- 구현 인계는 `.claude/skills/web-app-implementation/SKILL.md`를 가리킨다. 아직 실행하지 않은 계약은 구현 완료로 보고하지 않는다.
- 한국어 문안은 `.claude/skills/korean-prose/SKILL.md`로 다듬는다.
- UX·디자인 판단은 `knowledge/domain/web-app-ux-design.md`, 현재 첫 제안과 시안은 `docs/ux-design.md`,
  재설계 계약은 `docs/tasks/ux-redesign.md`에서 읽는다. 시각 선택은 강PD의 사용·선호로 확인하기 전까지 제안이다.
- Lighthouse의 계약·정책·소유권·코드·검사 상세 추적과 발견한 불일치는 `docs/research/lighthouse-contract-engineering.md`에 있다.

## 이번에 승인된 것과 새로 정할 것

강PD는 개인 영어 학습 서비스를 먼저 완성하고, Lighthouse의 기획·구현 기법을 모델과 스킬로 차용하도록 지시했다.
`docs/learning-service.md`의 여섯 약속은 이미 승인된 입력이다. 이 범위 안에서 과업과 수용 조건을 구체화할 때 같은
승인을 되묻지 않는다. 학습 완료 판정, 숙달 점수, 복습 간격처럼 새 제품 의미가 필요한 선택은 계약의 "사람이 정할 질문"에
근거와 선택지를 적는다. 현재 앱에서 기록 저장과 인증을 아직 구현하지 않았다는 사실만으로 특정 기술 선택을 확정하지 않는다.

계약 틀의 예시는 제품을 검토하는 가상 상황이다. 실제 강PD의 답, 힌트 사용, 수정이나 질문 기록으로 옮기지 않는다.
Lighthouse의 로컬 메모리 절차와 원본 저장소의 승인 체계는 가져오지 않는다. 외부 이슈·PR·배포를 고칠 권한은
이 스킬이 부여하지 않으며, `AGENTS.md`와 현재 세션의 승인 범위를 따른다.

## 검증 도구를 고를 때

기획 단계에서는 저장소 전체 검사를 실행할 필요가 없다. `package.json`과 실제 코드에서 수용 조건에 맞는 검사·브라우저
경로를 찾아 계약에 적는다. 실행 방법을 정한 칸과 실제 실행 결과를 적는 칸을 구분한다. 구현 뒤 명령과 배포 환경을
확인하는 절차는 구현 스킬이 맡는다.

## 절차를 비교해 볼 사례

다음은 스킬을 시험할 과업이며 수행 결과가 아니다. 같은 요구를 스킬 없이 기획한 계약과 비교해, 빠진 조건이나 실제 구현·검증
판단이 달라지는지 본다. 아직 이 비교를 실행하지 않았다.

| 가상 과업 | 계약에서 확인할 차이 |
| --- | --- |
| 풀이 도중 나갔다가 이어 한다 | 복원된 화면뿐 아니라 실제 입력·기록·읽기 경로가 검증 계획에 있는가. 기록과 AI 해설이 섞이지 않는가 |
| 답을 낸 뒤 힌트·수정·질답을 이어 간다 | 최초 답을 보존하고 실제 수행의 차이를 구분하는 조건이 있는가. 기다림·실패 뒤에도 현재 풀이를 이어 갈 수 있는가 |
| 기존 화면의 문구와 간격을 고친다 | 기존 약속을 보존하는 작은 변경을 불필요한 구조 개편이나 새 승인 절차로 키우지 않는가 |
