# model-update — 이 프로젝트에 맞춘 것

- 모델은 `knowledge/` 문서와 상태판 본문에 둔다. 정의는 `knowledge/model.md`, 개념은 `knowledge/concepts.md`를 따른다.
- 프로젝트가 키우는 모델은 `knowledge/domain/web-app-production.md`, `knowledge/domain/web-app-architecture.md`,
  `knowledge/domain/nextjs-development.md`, `knowledge/domain/web-app-ux-design.md`다. 학습 내용의 정본은 study-and-learn 프로젝트에 있고, 이 서비스의 요구는
  `docs/learning-service.md`가 소유한다.
- 강PD가 승인한 서비스 전환, 템플릿 구성, 세 제작 모델과 Lighthouse 기획·구현 기법의 모델·스킬 차용은 이번 작업의 범위다. 사용성에 대한 가설이나 새 학습 방식을 배움으로 확정하려면 먼저 강PD와 합의한다.
- `AGENTS.md`는 `knowledge/agents-md.md`, 스킬은 `knowledge/skills.md`를 따른다. 도메인 모델은 100줄을 넘으면 비대인지 검토한다.
