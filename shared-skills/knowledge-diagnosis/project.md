# knowledge-diagnosis — 이 프로젝트에 맞춘 것

- 평가기: `python3 scripts/knowledge-quality.py [<저장소> ...] [--out <파일>]`. 지식 지도는 `--map`을 붙인다.
  공식 테스트는 `python3 -m unittest discover -s scripts -p test_knowledge_quality.py`로 실행한다.
- 임시 파일: 고치기 전 값, 판정 의뢰서와 결과는 `.git/tmp-<이슈 번호>/`에 둔다. 커밋하지 않는다.
- 둘째 판정자: 작성에 참여하지 않은 하위 에이전트에게 읽기 전용으로 맡긴다. 모델, 추론 강도와 동시 실행 수는
  세션의 글로벌 기본 설정을 따르며 별도로 지정하지 않는다. 의뢰서에는 읽을 문서, 판정 질문, 센 단위와 보고 꼴을 적고,
  다른 판정자의 결과나 짐작은 적지 않는다.
- 상태판: `AGENTS.md`에 연결한 영어 감각 진행 상태판을 쓴다. 보고 한 줄은 "현재 사실"의 평가기 줄에 둔다.
- 새 씨앗을 받았다는 사실만으로 전체 진단을 시작하지 않는다. 실제 진단 요청이 있을 때 이 스킬을 쓴다.
- 이슈·문서 변경은 `AGENTS.md`와 현재 세션에서 승인한 범위를 따른다. 이 스킬이 새 게시 권한을 부여하지 않는다.
