# 개인 영어 학습 서비스의 요구사항

2026-10-26 강PD는 개인 학습부터 완성하고, 지금의 영어 감각·책 장면 학습을 다루기로 정했다.
아래 여섯 관계를 모델과 서비스 구성의 기준으로 사용하도록 승인했다. 이후 웹앱 제작 모델의 대상을 다시 정하면서,
이 내용은 제품 요구사항으로 구분했다. 학습 내용의 정본은 study-and-learn 프로젝트다.

## 승인된 약속

| 약속 | 서비스가 지킬 것 |
| --- | --- |
| 장면에서 표현을 고른다 | 문제에 맥락을 함께 보이고 장면을 표현 선택의 기준으로 삼는다 |
| 수행의 차이를 남긴다 | 정답 여부와 함께 처음 답, 선택한 까닭, 힌트, 스스로 고친 답과 질답을 구분해 남긴다 |
| 먼저 떠올리고 푼다 | 답을 제출한 뒤 피드백과 추가 질문을 이어 간다 |
| 실제 막힌 곳을 다시 꺼낸다 | 지난 풀이를 복습의 재료로 삼고 다음 유닛은 기존 로드맵을 따른다 |
| 멈춘 맥락에서 이어 한다 | 문제 도중 나가도 진행 상태와 풀이 맥락을 복원한다. 편리함은 사용 뒤 확인한다 |
| AI와 실제 수행을 구분한다 | AI의 판단을 학습 완료나 확정된 배움으로 자동 기록하지 않는다 |

## 현재 구현과 남은 일

기존 공개 콘텐츠, 장면 퀴즈와 문장 해설기를 Next.js·Cloudflare로 이관한 전환본이 있다.
기본 화면(have)과 읽기·사전 훈련 수업은 최초 답·수정·AI 질답과 같은 브라우저 임시 복원을 제공한다.
개인 계정·서버 기록 DB·다른 기기 복원과 기존 파일 기록 연결은 아직 구현하지 않았다.
아직 정하지 않은 숙달 점수, 복습 간격과 학습 완료 판정을 임의로 도입하지 않는다.

강PD는 UX 모델을 준비하고 앱 디자인을 처음부터 다시 하도록 지시했다. 표현 감각을 이해하는 이미지와
터미널처럼 이어지는 AI 대화, 전체 공개 문항과 추가한 참고 자료를 가리키는 목차·자료 스택을 사용한다.
현재 디자인은 `docs/ux-design.md`다. 이전 시안·단일 문제·퀴즈·문서 배치의 실행은 각각 작업 계약에 남아 있다.

이후 콘텐츠가 가려져 어색하다는 강PD의 피드백에 따라 넓은 화면에서는 콘텐츠 문서 옆에 AI 대화를 둔다.
have 감각 설명·공개 예시와 일곱 문제를 처음부터 펼쳐 놓고 웹문서처럼 페이지를 내려 읽는다. 원하는 문제를 이전 답 제출 없이 선택해 풀며 문서 순서와 실제 수행 순서를 분리한다. 첫 답·수정은 퀴즈가 있는 본문 자리에서 입력하고(첫 답을 내면 AI 피드백이 그 퀴즈 안에 나온다), 대화 칸은 질문과 한 줄 요약 타임라인을 맡는다. 넓은 화면에서 대화는 옆에 머물고 좁은 화면은 탭 없이 세로 흐름으로 이어 간다.
자료를 읽는 위치와 AI 질문 대상은 별개이며 대상별 초안·수행·응답을 보존한다. 카드 추가나 자료 열람을 학습 완료로 취급하지 않는다.
현재 범위·예측·실행·모델 판단은 `docs/tasks/content-chat-workspace.md`가 소유한다. 모델을 먼저 고친 뒤 실제 과업으로 확인한다.

현재 공개 감각 자료는 have·get·be·go·come, 장면 퀴즈는 have 일곱 문항이다. 읽기 이야기 15편과 책·영화 사전 훈련 유닛 13개도 같은 작업 공간의 수업이다.
이야기는 시간을 재어 읽고 본문을 가린 뒤 일곱 문제를, 카드는 표현 카드마다 뜻과 힌트로 떠올려 빈칸을 푼다(표현·감각·예문은 첫 답을 낸 뒤에 열린다). 세 수업(장면 포함) 모두 전체 문서를 먼저 읽고 원하는 문제를 골라 풀며,
첫 답·수정을 문제가 있는 본문에서 입력하고 옆 대화는 질문과 한 줄 요약을 맡는다. 이야기·카드의 정답·해설·빈칸 답과 카드의 표현·감각·예문·근거는 서버 정본에만 있고 첫 답 뒤에 판정 응답으로 온다. 판정은 서버가 정본과 비교한 결과이며(약속 6),
AI는 이야기·카드에서는 사용자가 설명 요청이나 질문을 보낼 때만 부른다. 장면은 첫 답을 내면 AI 피드백을 자동으로 한 번 요청하고(강PD 결정) 그 뒤는 질문을 보낼 때만 부른다. 수업마다 기록이 따로 같은 브라우저에 남고 완료·숙달·진행률은 만들지 않는다.
홈의 "수업 목록" 창과 각 수업의 도구 막대가 수업 사이를 잇는다(수업 사이 "이어 하기"는 없다). 화면은 `docs/ux-design.md`, 근거와 미확인은 `docs/tasks/workspace-lessons.md`에 있다.
come 유닛 개방과 정본 진도 연결은 아직 없다.
미전송 초안을 자동 제출하거나 AI의 설명을 강PD의 배움으로 확정하지 않는다. 브라우저 임시 기록은 개인 서버 기록이나 정본을 대신하지 않는다.

2026-10-28 강PD는 문장 해설기(`/ask/`)의 요청과 결과도 기록으로 남기고 결과에 추가 질문할 수 있게 하도록 정했다.
요청 문장·모드·해설 전문과 이어 묻는 질답·초안을 요청별로 연결하며 새 해설로 지난 결과를 덮지 않는다.
브라우저 복원 사본·내보내기와 서버 보관의 차이를 표시한다. 보관 범위 선택과 실제 검증은 `docs/tasks/ask-conversations.md`가 소유한다.

제작 판단은 `knowledge/domain/web-app-production.md`, 구조 판단은 `knowledge/domain/web-app-architecture.md`,
Next.js 구현 판단은 `knowledge/domain/nextjs-development.md`를 따른다. 이 문서의 약속을 고칠 때는 강PD와 합의한다.
