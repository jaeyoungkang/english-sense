# 상단 감각 자료와 순차 학습 대화

이 문서는 이전 단일 문제 구현의 수용 근거다. 현재 퀴즈 아티팩트 구현·모델 판단은 `docs/tasks/quiz-artifacts.md`에서 확인한다.

## 과업과 승인 근거

2026-10-26 강PD는 이미지란 책 장면이 아니라 have 같은 표현의 감각을 나타내는 그림이라고 바로잡았다.
학습은 탭 전환보다 채팅처럼 콘텐츠가 쌓이는 방식이 좋으며, 감각 자료는 상단에 두도록 정했다.
현재 기본 화면을 이 방향으로 바꾸고 기존 실제 AI 대화·수행 보존·실패 처리·브라우저 임시 복원을 유지한다.
제품 요구는 `docs/learning-service.md`, 디자인은 `docs/ux-design.md`가 소유한다.

기대는 표현의 감각을 계속 참고하며 문제·답·피드백·수정의 순서를 같은 대화에서 다시 읽을 수 있다는 것이다.
근거는 UX 모델 관계 2·8·9·11·12와 아키텍처 모델의 상태 수명·응답 채택 관계다.
사전부검에서는 상단 자료가 모바일 입력을 가리는 문제, 수정과 응답을 종류별로 묶어 순서를 잃는 문제,
기존 기록을 지우거나 없는 시각을 추정하는 문제를 확인 대상으로 삼았다. 편리함과 학습 효과는 사용 뒤 판단한다.

## 시작과 진행

- 상단에서 have의 감각 이미지와 핵심 설명을 계속 참고한다. 모바일에서는 작게 접어 두고 필요하면 펼친다.
- 감각의 정본은 study-and-learn의 `knowledge/domain/english-senses.md` have 줄과 `content/scene-sense/have.md`다.
- 핵심은 주어가 자기 영역을 두고 그 안에 무언가가 놓여 있다는 것이다. 물건뿐 아니라 몸·마음·시간·할 일·지난 일도 영역이 된다.
- 아래에는 현재 책 장면·문제가 나오고, 실제 처음 답과 이유·AI 응답·수정·질문이 일어난 순서대로 추가된다.
- 처음 제출과 수정은 덮어쓰지 않고, AI에 보낼 수행과 미전송 초안을 구분한다.
- 과거 대화를 읽는 동안 새 응답이 와도 읽기 위치를 끝으로 끌지 않는다. 새 응답으로 이동할 수단을 제공한다.
- 기록·다른 자료를 여는 보조 도구는 둘 수 있지만 학습의 다음 단계를 보기 위해 탭을 바꾸지 않는다.

## 구조 영향과 소유권

영향은 `reshape`다. API 계약과 서버의 사용량·공급자·정본 문제 조회는 유지하고 클라이언트의 표현·임시 보관 형태를 바꾼다.
`components/learning-workspace.tsx`가 대화의 표시 순서와 상단 자료를, `app/workspace.css`가 크기·고정·읽기 영역을 맡는다.
브라우저 기록에는 실제 행동 순서를 표현할 수단을 두되 기존 v1 원본은 읽기만 하고 새 버전의 키로 옮긴다.
이전 기록에 수정·응답 간 순서가 없으면 이전 기록 묶음으로 구분한다. 새 사건부터 실제 추가 순서를 기록한다.
서버 계정 기록과 다른 기기 동기화는 이번 변경에 포함하지 않는다.

## 이미지와 자료의 범위

`have-sense.webp`는 have의 관계를 설명하려고 생성한 그림이다. 사람을 둘러싼 영역 안에 손전등·하트·시계·몸 모양·
체크리스트와 발자국이 함께 놓여 있다. 그림의 도상과 배치는 정본 감각을 옮긴 설계 추론이다.
'내 영역 안에 놓여 있다. 물건뿐 아니라 몸·마음·시간·할 일·지난 일도 내 영역이 됩니다'라는 본문을 가까이 둔다.
정답 문장·선택지 종류를 그림에 넣지 않는다. 책 복도 삽화는 현재 학습의 기본 이미지로 사용하지 않는다.
이미지의 실제 의미와 없는 세부를 alt에 지어내지 않는다.

## 유지하는 운영 정책과 한계

- 제출 전에는 준비된 과업 안내, 제출 뒤에는 실제 AI 다중 대화를 제공한다. 제출 전 생성형 힌트는 아직 없다.
- 현재 AI에는 정본 본문·제출한 수행·보낸 대화 텍스트가 전달된다. 미전송 초안·이미지 픽셀을 자동으로 보내지 않는다.
- 요청·응답 한도는 `lib/learning-chat-contract.ts`, Origin·사용량·timeout·응답 채택은 현재 아키텍처를 따른다.
- 같은 브라우저 임시 보관이며 개인 인증·서버 기록 DB·기기 간 동기화·서버 멱등 재시도는 미구현이다.
- 기존 have 책 장면 첫 문제를 쓰며 다음 로드맵 유닛이나 숙달·완료를 새로 정하지 않는다.

## 결과

2026-10-26 타입 검사·단위 33개, Cloudflare 빌드와 로컬 Workers 브라우저 24개가 통과했다.
운영 주소 `https://english.artificialmind.kr/`의 새 작업 공간 검사 14개도 통과했다.
브라우저 자동 검사는 공급자 응답을 모의한다. 별도 빈 브라우저에서 실제 AI 응답 1회(200·846자)를 받고
새로고침 뒤 최초 답·요청·응답 복원과 자동 재호출 없음(총 1회)을 확인했다. 서버 코드는 이번에 바꾸지 않았다.
운영 배포 판은 `6f81f693-9939-441d-8867-294b55903990`이다.

검토 중 보관 대화의 이벤트가 누락된 기록도 정상으로 읽는 오류를 찾아, 보관 요청·응답 대응 검사와
원문을 덮어쓰지 않는 회귀 검사를 추가했다. 현재 화면 증거는 `design/screenshots/README.md`에 연결한다.
이전 패널 방식의 실제 AI 2턴 검증은 서버의 기존 근거이며 새 순서·상단 고정·이관의 근거와 구분한다.
검사는 Chromium의 모바일 에뮬레이션이며 실제 iOS 소프트웨어 키보드·화면 읽기 도구는 확인하지 않았다.
강PD의 실제 학습·사용성 평가 결과는 아직 없다. 이번 구현 검증을 learn 기록으로 쓰지 않는다.
