# 외부 공개 읽기·영어 감각 훈련 서비스 작업 계약

[학습 서비스 범위](../learning-service.md), [웹 UX 설계](../ux-design.md), [수업 작업 공간](workspace-lessons.md)을 바탕으로, 수업 목록의 읽기 이야기 15편을 외부 방문자와 검색 엔진에 정식 공개하고 이야기 읽기·퀴즈 풀이·영어 감각 연결 흐름을 다듬는 작업 계약이다.

## 사용자와 과업

- **주 사용자:** 검색 엔진에서 영어 읽기 이야기나 영어 표현·감각 설명을 찾아 들어온 외부 방문자, 그리고 웹에서 영어 감각·원서 장면 학습을 이어 가는 학습자.
- **핵심 과업:** 검색이나 수업 목록으로 이야기 페이지(`/reading/<id>/`)에 들어와 영어 이야기를 바로 읽고, 아래에 이어지는 7개 문제를 풀며 정본 판정과 해설을 확인하고, 막히는 지점은 오른쪽 대화창에서 AI에게 물어보며, 이야기에서 다룬 기본동사 감각 설명이나 사전 훈련 유닛·다음 이야기로 이어서 공부한다. 원하면 시간 제한 읽기(`읽기 시작`)를 골라 읽은 시간을 재고 본문을 가린 채 기억으로 문제를 풀어 볼 수도 있다.
- **시작에서 끝까지:**
  1. 방문자가 검색 결과나 `/reading/`, 수업 목록 창에서 이야기 페이지(`/reading/<id>/`)를 연다.
  2. 첫 화면(서버가 내려주는 첫 HTML 포함)에 이야기 제목, 한국어 안내·줄거리 소개, 영어 본문 전체, 7개 4지선다 문제 양식이 모두 열려 있어 방문자가 곧바로 읽고 첫 답을 남길 수 있다.
  3. 방문자가 시간을 재어 읽고 본문을 가린 뒤 기억에 기대어 풀어 보고 싶다면 본문 위의 선택 상자에서 읽기 수준(`여유 있게`·`보통`·`빠르게`)을 고르고 `읽기 시작`을 누른다. 읽는 동안에는 시계가 흐르고 문제 입력이 잠시 닫히며, `다 읽었습니다`를 누르거나 제한 시간이 지나면 본문이 가려지고 문제가 다시 열린다.
  4. 각 문제에서 보기를 골라 `첫 답 남기기`를 누르면 서버가 AI 없이 정본 답과 비교해 판정하고, 문제 바로 아래에 정본 답·정본 해설·근거·관련 표현 카드 링크를 보여 준다.
  5. 설명이 더 필요하면 `AI에게 설명 요청`을 누르거나 오른쪽 대화창에 질문을 적어 보낸다.
  6. 문서 끝에서 이 이야기와 이어지는 기본동사 감각 설명(`/have/`, `/get/`, `/be/`, `/go/`, `/come/`)이나 짝 사전 훈련 유닛, 이전·다음 이야기로 이동해 훈련을 이어 간다.

## 수용 조건

- **`open-reading-and-quiz` (본문과 문제 기본 공개):**
  - `/reading/<id>/` 첫 응답 HTML과 초기 화면에 이야기 본문(`.lw-story-body`)과 7개 문제의 첫 답 양식(`.lw-story-form`)이 처음부터 열려 있다.
  - 방문자가 `읽기 시작`을 누르지 않아도 본문에 밑줄·형광펜·메모를 남기거나 7개 문제 가운데 원하는 문제에 바로 첫 답을 남기고 서버 판정(`/api/lesson-check/`)과 AI 질문(`/api/learn-chat/`)을 쓸 수 있다.
- **`optional-timed-reading` (선택형 시간 제한 읽기와 본문 가리기):**
  - 본문 위 `.lw-reading-gate`에서 세 가지 읽기 수준(`여유 있게`·`보통`·`빠르게`)을 고르고 `읽기 시작`을 누르면 시간 제한 읽기가 시작된다.
  - 읽는 중(`phase === "reading"`)에는 남은 시간과 지난 시간이 표시되고 문제 풀이와 대화 입력이 닫히며(`읽기를 마치면 열립니다.`), `다 읽었습니다`를 누르거나 제한 시간이 지나면(`phase === "ended"`) 본문이 가려지고 문제가 열린다.
  - 본문이 가려진 뒤에는 7개 문제에 모두 첫 답을 남겨야 `본문 확인하기`로 본문을 다시 펼쳐 볼 수 있다.
- **`draft-removal-and-clean-ui` (15편 정식 공개 및 외부 화면 정리):**
  - `content/reading.json`의 이야기 15편(일반 이야기 2편 + 사전 훈련 짝 이야기 13편) 모두 `draft: false`로 공개한다.
  - 페이지 제목(`<title>`), `/reading/` 목록, 수업 목록 대화상자, 이야기 작업 공간 상단과 머리말에 `초안` 꼬리표나 `"강PD가 아직 읽고 통과시키지 않은 이야기"` 안내가 나타나지 않는다.
  - 인증하지 않은 외부 방문자에게는 이야기 화면에서 개인용 동기화 단추(`개인 서버 보관 연결`)나 `"계정·개인 서버 저장 없음"` 문구를 노출하지 않는다.
- **`seo-metadata-and-jsonld` (검색 유입 메타데이터와 구조화 데이터):**
  - `/reading/`과 `/reading/<id>/` 15편 각각에 한국어 제목·핵심 줄거리·훈련하는 영어 감각/표현을 담은 고유한 `<title>`과 `<meta name="description">`, Open Graph 설명을 넣는다.
  - `/reading/<id>/` 페이지에 `BreadcrumbList`와 함께 `Article` JSON-LD 구조화 데이터를 넣는다.
- **`sense-and-story-navigation` (영어 감각·사전 훈련·다음 이야기 연결):**
  - 이야기 문서 머리말과 문서 끝에 이야기 줄거리·훈련 초점 안내, 함께 읽을 기본동사 감각 문서(`/have/`, `/get/`, `/be/`, `/go/`, `/come/`), 짝 사전 훈련 유닛 링크(짝 이야기인 경우), 이전·다음 이야기 이동 링크를 둔다.
- **`canonical-secret-boundary` (정본 답·해설·근거 비노출 불변식 유지):**
  - 본문과 문제를 첫 HTML에 공개하더라도 15편 모든 문제의 정본 답(`answer`), 정본 해설(`explain`), 근거(`basis`)는 서버 판정 전까지 HTML, RSC 페이로드, 메타데이터, 클라이언트 스크립트 어디에도 실리지 않는다.

## 화면·구조 영향

- **콘텐츠·메타데이터 계층:**
  - `content/reading.json`: 15편 이야기의 `draft`를 `false`로 바꾼다.
  - `lib/story-lesson.ts`: 15편 이야기별 한국어 부제, 검색·안내용 줄거리와 표현 감각 설명, 연관 기본동사 감각 링크(`senseGuides`), 이전·다음 이야기 안내(` getStoryGuide`, `getStoryNavigation`)를 순수 함수로 제공한다. 정본 해설(`explain`)이나 근거(`basis`) 문구는 포함하지 않는다.
  - `lib/server/study-source.ts`: `/reading/`과 `/reading/<id>/`의 `title`·`description`을 이야기별 안내로 풍부하게 만들고, 이야기 페이지에 `ld: "article"`을 지정한다.
- **상태·작업 공간 계층:**
  - `lib/lesson-workspace-state.ts`: `lessonAccess`와 `isLessonState`가 시간 제한 읽기를 시작해 아직 끝나지 않은 동안(`start && !end`)에만 이야기 문제를 잠그고(`reading-not-ended`), 읽기 시작 전(`!start`)이나 읽기 종료 후(`end`)에는 문제를 열어 둔다(`open`).
  - `components/story-workspace.tsx`: `phase === "before"`(초기 서버 렌더링 `"loading"` 포함)에서도 `.lw-reading-gate` 아래에 `.lw-story-body`를 함께 그리고, 문서 끝에 연관 영어 감각 자료·짝 유닛·이전/다음 이야기 탐색 영역(`.lw-story-Transfer` / `.lw-story-nav`)을 둔다.
  - `components/workspace-shell.tsx`, `components/personal-record-sync.tsx`: 외부 방문자(비인증 브라우저 임시 기록 상태)에게 불필요한 개인 서버 미연결 문구를 숨길 수 있게 한다.

## 검증 계획

- **단위 검증 (`npm test`):**
  - `tests/lesson-catalog.test.ts`, `tests/story-lesson-page.test.ts`: 15편 공개 투영과 페이지 props, 이야기 안내 메타데이터에 `answer`·`explain`·`basis`가 포함되지 않는지 확인한다.
  - `tests/lesson-workspace-state.test.ts`: 이야기 수업에서 시간 제한 읽기 시작 전(`!start`) 바로 첫 답을 제출·판정·질문할 수 있고, 시간 제한 읽기를 시작한 뒤 끝나기 전(`start && !end`)에는 문제 제출과 질문이 막히며, 읽기가 끝난 뒤(`end`) 다시 열리는지 확인한다.
- **브라우저 E2E 검증 (`npm run test:e2e`):**
  - `tests/e2e/story-lessons.spec.ts`, `tests/e2e/study-content.spec.ts`, `tests/e2e/reading-levels.spec.ts`, `tests/e2e/notes.spec.ts`:
    - 첫 응답 HTML과 초기 화면에 이야기 본문과 7개 문제 양식이 열려 있고, `초안` 표시가 없으며, 정본 해설·근거는 한 글자도 새지 않는지 확인한다.
    - 방문자가 타이머 없이 곧바로 첫 답을 남겨 서버 판정과 정본 해설을 받을 수 있는지 확인한다.
    - 방문자가 `읽기 시작`을 누르면 타이머가 돌며 문제가 잠기고, `다 읽었습니다` 또는 시간 마감으로 읽기가 끝나면 본문이 가려진 채 문제를 풀고, 7개 문제를 모두 푼 뒤 `본문 확인하기`가 열리는지 확인한다.
    - 이야기 페이지에 `Article` JSON-LD와 한국어 안내, 기본동사 감각 링크, 이전·다음 이야기 링크가 동작하는지 확인한다.
- **빌드·런타임 검증 (`npm run check`, `npm run cf:build`):**
  - 정적·동적 라우트 빌드와 Cloudflare Worker 번들 생성이 오류 없이 통과하는지 확인한다.
