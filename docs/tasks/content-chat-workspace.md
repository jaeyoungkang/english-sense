# 전체 학습 문서를 읽으며 AI와 푸는 작업 공간

## 승인과 물음

강PD는 “지금 1개씩열리는데 문서가 다 표시되어 있어야한다. 웹문서 읽듯이 쭉내리면서 읽는거야. 그러면서 문제도 푸는거지”라고 요구하고, 이 조건으로 모델 재검토와 화면 수정을 지시했다.
현재 have 학습의 감각 설명·공개 예시와 일곱 문제를 처음부터 읽는 문서로 만든다. 기본 자료 외 get·be·go 참고 자료는 기존처럼 추가해 읽는다.
이전 입력 통일은 첫 답·수정·질문을 오른쪽에 모았지만 문서 자체는 실제 열린 카드와 다음 답 제출 조건에 묶여 있었다.
이번 물음은 전체 문서를 자유롭게 읽고 원하는 문제부터 푸는 흐름이 가능한가다. 입력 통일과 첫 답 보존은 유지한다.

## 사용자 과업과 수용 조건

- 빈 브라우저에서도 have 설명·공개 예시·일곱 문항의 장면·발문·보기를 모두 본다. 본문·목차는 동일한 전체 항목을 가리킨다.
- 본문은 페이지 전체 스크롤로 연속해서 읽는다. 넓은 화면에서 목차와 대화는 옆에 머물며 대화만 내부 스크롤을 사용한다.
- 이전 답을 제출하지 않아도 7번부터 선택해 풀고 2번으로 돌아갈 수 있다. 다음 문제 추가·잠금 해제 조작은 없다.
- 문서를 읽거나 목차를 이동해도 입력 대상·초안·실제 사건은 바뀌지 않는다. 전체 표시로 선택·수행·요청을 합성하지 않는다.
- 본문의 ‘이 퀴즈로 이어 가기’ 또는 ‘함께 풀 문제’로 명시적으로 선택한다. 처음 선택하는 문제의 작업 상태만 만들고 AI는 부르지 않는다.
- 첫 답·이유·수정·질문은 오른쪽 한 작업 영역에서 구분해 입력한다. 제출 전 질문은 준비 안내이며 첫 답은 명시적 제출로만 남긴다.
- 실제 선택·제출·수정·요청·응답 순서는 대화에 보존하고 문항 번호·본문·목차는 공개 문항 순서로 고정한다.
- 대기 중 다른 문제를 선택하고 초안을 써도 응답은 원래 문제에 붙고 페이지 위치를 바꾸지 않는다. 모든 입력 단계에서 응답을 중단할 수 있다.
- 기존 일부 학습 v3·v1/v2 원문·초안·스레드·옛판 스냅샷을 보존한다. 옛판 문제는 해당 위치에서 당시 내용으로 읽고 AI 전송을 막는다.
- 자료 스택의 최근 추가 순서·하나 펼침과 자료 추가를 유지한다. 본문 예시는 모두 이어 읽고 정답·모범 답·비공개 해설은 선공개하지 않는다.
- 좁은 화면에서는 문서 다음 대화로 명시적으로 오가며 초안·문서 앵커를 유지한다. 탭·본문을 덮는 채팅 창은 만들지 않는다.

같은 확인을 고쳐 재는 일이 3회를 넘거나 요구가 충돌하면 멈추고 원인을 보고한다. 본문 공개와 정답 선공개를 혼동하지 않는다.

## 구조 판단과 호환

영향은 reshape다. 공개 문서와 실제 학습 사건의 투영 책임을 분리하고 페이지 스크롤·옆 대화의 경계를 바꾼다.
본문은 catalog의 공개 일곱 문항을 정규 순서로 투영한다. 기존 동일 questionId가 있으면 당시 snapshot을 쓰고, 없으면 저장하지 않는 읽기용 빈 snapshot을 만든다.
실제 선택할 때만 누락된 artifact와 card 사건을 만든다. 빈 문제를 자동 저장하거나 card 사건 검증을 완화하는 방식은 쓰지 않는다.
학습 v3의 필드·검증·기존 사건·복원은 유지한다. 번호는 선택 순서가 아니라 catalog questionId 순서에서 구한다.
기존 ‘다음 추가’ 함수는 이전 상태 검사의 호환 경로이며 제품은 사용하지 않는다. 모든 실제 선택은 자유 선택 함수로 이어진다.
본문·목차는 같은 문서 노드를 쓰고 대화는 원본 events 순서를 그대로 쓴다. 공개 문서 순서를 events 순서로 계산하지 않는다.
자료 afterEventId는 그 시점까지 마지막 card의 본문 위치를 뜻한다. reply의 대상과 삽입 위치를 혼동하지 않는다. 알 수 없는 앵커·문항은 끝에 안내해 보관한다.
기존 문서 UI v1·레이아웃 UI v1을 읽고 본문 앵커·대화 읽기 위치를 복원한다. 페이지 위치 저장은 명시적 읽기 이동과 분리하며 AI 응답은 페이지를 움직이지 않는다.
API·공급자·한도·개인 서버 저장·인증·come 유닛·새 학습 완료 판정은 바꾸지 않는다.

사전부검: 전체 문항 표시를 일곱 학습 사건 생성으로 구현하면 하지 않은 수행을 기록한다. 공개 문서 투영과 실제 선택을 분리한다.
페이지 높이가 길어진 뒤 대화를 따라가려고 본문을 자동 이동하면 읽던 위치를 잃는다. 대화는 옆에서 내부 스크롤하며 명시적 이동만 페이지를 움직인다.
자료 고정 높이 때문에 목차 앵커 제목이 가려질 수 있으므로 실제 렌더링과 hit-test로 확인한다. 작은 화면은 명시적 본문·대화 왕복을 검증한다.
