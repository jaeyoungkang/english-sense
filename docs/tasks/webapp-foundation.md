# 웹앱 제작 기반 전환

## 승인 범위와 현재 물음

강PD는 기존 서비스를 Next.js·Cloudflare로 옮기고 project-base 템플릿으로 구성하도록 지시했다.
이어서 개인 영어 감각·책 장면 학습을 먼저 완성하고, 웹앱 제작·아키텍처·Next.js 개발 모델을 나누며,
Lighthouse의 기획·구현 기법을 모델과 스킬로 차용하도록 정했다.

이 계약은 진행 중인 기반 전환을 새 기획 스킬로 정리한 것이다. 작업 전에 이 스킬을 써서 효과가 나아졌다는 기록은 아니다.
현재 물음은 기존 공개 기능을 보존한 실행 기반과 이후 개발의 판단 모델·수행 방법이 맞물렸는가다.
개인 학습 기록·인증·복원 자체의 구현은 별도 사용자 과업으로 잇는다.

## 과업과 기대 결과

기존 주소에서 감각 설명을 읽고 장면 퀴즈를 풀며 문장 해설을 받는 과업을 보존한다.
화면·서버·한도 처리의 실행 위치를 Cloudflare로 옮기고, 유지·확장을 맡는 사람이 모델과 스킬에서 선택의 이유와 절차를 찾을 수 있게 한다.
학습 효과나 사용 편의가 나아졌는지는 이번 기술 전환의 검사로 판정하지 않는다.

## 수용 조건과 근거

| 조건 | 필요한 실제 경로 | 확인 결과와 범위 |
| --- | --- | --- |
| 기존 내용과 문제를 보존한다 | 원본 자료와 이관 데이터 대조 | 페이지 12개, 문제 30개, 쓰임 전환 26개를 대조했다 |
| 화면이 실제로 조작된다 | Workers 자산 → hydration → 선택·입력·제출·다시 풀기 | PC·모바일 브라우저 검사 10개가 로컬과 배포된 Workers 주소에서 각각 통과했다 |
| API 성공·실패·한도 경계가 동작한다 | HTTP 입력 → 한도 → 공급자 → 응답 검증 | 단위 검사 22개 통과. 공급자 모의 응답 검사는 실제 호출과 구별했다 |
| 실제 공급자 연결을 확인한다 | 배포된 브라우저 → API → Claude | 영어 해설과 한국어 변환의 200 응답, 감각 항목과 대비 결과를 확인했다 |
| 제작 지식을 목적에 맞게 나눈다 | 세 모델의 개념·관계·규칙·출처 → 두 스킬의 배경과 절차 | 독립 교차 검토, 골격·참조 검사와 익명 스킬 라우팅 검토를 진행했다 |
| 기존 운영 주소를 이전한다 | 두 도메인의 DNS·Worker → 실제 페이지와 API | 아직 운영 주소 전환 전이다. 완료하면 이 칸을 실제 관찰로 고친다 |

정적 자산 설정을 바꾼 뒤 이전 빌드를 사용해 조작이 죽는 실패를 브라우저 검사에서 발견했다.
같은 설정으로 빌드한 산출물로 다시 확인했다. 단위·타입 검사는 이 실패의 성공 근거가 아니었다.

## 구조 영향

영향은 `reshape`다. 기존 정적 생성기·GitHub Pages와 별도 Python API에서 Next.js·Workers로 실행 위치가 바뀐다.
현재 선택은 OpenNext, 서버 API와 SQLite 기반 일일 한도 객체다. 개인 기록 DB나 인증 계층이 이미 생겼다는 뜻은 아니다.
실제 책임과 의존 방향은 `docs/architecture.md`가 소유한다.

원래 소유자는 정적 HTML 생성기와 별도 API 서버였고, 선택한 소유자는 Next.js 페이지·HTTP 진입점·서버 처리와 Worker다.
별도 서버에 계속 의존하는 안은 Cloudflare 체제로 옮기라는 지시와 맞지 않아 이번 실행 경로로 선택하지 않았다.
현재 Cloudflare의 신규 앱 권장은 vinext지만, 이 전환본은 실제 Next.js·OpenNext 조합을 빌드하고 배포해 검증했다.
지원 기능이 달라지는 다음 선택에서는 설치 버전과 어댑터를 다시 비교한다.

## 변경 범위와 인계

직접 바꾸는 것은 웹 앱 코드·배포 설정, 공통 템플릿 기반, 세 제작 모델과 두 스킬, 현재 구조·출처·검증 문서다.
Lighthouse는 고정 커밋의 읽기 자료로만 사용한다. study-and-learn의 학습 모델·원문·실제 수행 기록은 수정하지 않는다.
기존 운영 설정을 바꾸면 marketing 프로젝트의 `english-site.md`도 현재 사실에 맞춘다.
큰 서비스 재구성에 앞서 다음 과업은 승인된 여섯 약속을 실제 학습 흐름과 수용 조건으로 구체화하는 것이다.

## 사람의 사용으로 확인할 것

웹에서 학습을 시작하고 이어 가는 일이 터미널보다 편리한지는 아직 확인하지 않았다.
AI 해설이 실제 이해를 돕는지와 강PD가 무엇을 배웠는지도 기술 검사로 대신 기록하지 않는다.
