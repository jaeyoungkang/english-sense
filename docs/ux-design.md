# 콘텐츠 문서와 AI 대화를 나란히 읽는 화면

강PD가 승인한 현재 방향은 감각 자료·퀴즈를 읽으면서 옆에서 AI와 대화하는 작업 공간이다.
현재 계약과 모델 판단은 `docs/tasks/content-chat-workspace.md`, 원칙은 `knowledge/domain/web-app-ux-design.md`가 소유한다.
이전 단일 세로 배치의 실행 근거는 `docs/tasks/document-workspace.md`에 있다.

## 넓은 화면

접을 수 있는 목차 옆에 콘텐츠 문서와 AI 대화를 나란히 둔다. 문서와 대화는 각각 스크롤한다.
문서는 흰 면·절 번호·읽기 폭·서지·감각 이미지·문제로 구성한다. 감각 자료와 퀴즈를 추가하면 목차가 생긴다.
채팅은 처음 답·수정·질문·AI 응답과 실제 발생 순서를 보여 주며, 입력창도 채팅 칸에 둔다.
긴 응답이 도착해도 문서의 읽던 위치와 작성 중인 답은 그대로다.

## 같은 수행에 연결하는 두 칸

퀴즈 본문·보기와 제출한 수행의 열람은 문서에 둔다. 첫 답·이유·수정·질문 입력은 오른쪽 대화 작업 영역에 모은다.
대화의 현재 대상 아래에서 첫 답을 제출하고 피드백과 질답을 잇는다. 첫 답·수정·질문은 표시와 제출 행동을 구분하며 질문을 첫 답으로 저장하지 않는다.
대화에 나타난 퀴즈 표식을 누르면 그 본문을 읽는다. 자료·목차·본문 참조 이동은 대상을 바꾸지 않는다.
본문의 ‘이 퀴즈로 이어 가기’와 대화의 대상 선택으로만 입력 대상을 바꾼다. 대상별 미전송 초안은 유지한다.
퀴즈별 처음 답·수정·대화·초안과 자료 판은 기존처럼 연결한다. 수정 입력도 대상 퀴즈를 표시한다.
이전 기록·재시도·취소·새 대화와 자료 판 불일치의 처리도 유지한다.

## 문서의 목차와 자료 스택

목차는 실제로 추가한 감각 자료와 열린 퀴즈만 가리킨다. 앞으로 열 항목을 진도처럼 넣지 않는다.
자료 스택은 콘텐츠 칸에서 최근 추가 순서로 놓고 하나만 펼친다. have를 다시 펼쳐도 본문·목차 순서를 바꾸지 않는다.
삽입 앵커를 잃은 자료는 위치 미확인 안내와 함께 끝에 보관하고 실제 학습 사건 순서는 보존한다.
문서에 남는 카드의 수행 열람과 대화의 사건 흐름은 같은 수행의 다른 표현이다.

## 좁은 화면과 재개

좁은 화면에서는 문서 다음에 대화를 자연스러운 세로 흐름으로 둔다. 전역 고정 입력창·자료로 본문을 누르지 않는다.
탭 없이 자료·문제·대화로 이동하며 명시적 이동은 페이지를 움직일 수 있다. 각 재개 위치·대상별 초안과 풀이를 유지하고 새 응답이 콘텐츠 읽기를 강제로 끊지 않는다.
문서는 본문 앵커로, 채팅은 별도의 읽기 위치·끝 따라가기 정책으로 재개한다. 새 응답은 과거 읽기를 강제로 끊지 않는다.
기존 문서 UI v1과 학습 v3의 읽기 호환을 유지하고 레이아웃 설정은 별도로 보관한다.

현재 감각 자료는 have·get·be·go이고 대화형 퀴즈는 have 일곱 문항이다. 제출 전은 준비 안내, 제출 뒤는 실제 AI다.
서버 DB·계정·다른 기기 동기화·come 유닛은 아직 없다. 나란한 배치의 편리함은 강PD의 사용으로 확인한다.
